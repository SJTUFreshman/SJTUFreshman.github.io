## 照片级质量阻塞项

1. **前后舱照明失衡。** 三相都有明显的前舱欠亮、后舱白亮，左右转头时两者直接相接。白天的窗口和局部窗沿变亮，但 Cupola 大片暗面、设备支撑和上下方向仍缺少可读层次。后舱的强热点又压弱白色表面的细节。这是本轮最直接的拒收原因；仅提高全局曝光会同时加重后舱问题。
2. **后视顶部黑区尚未解释。** 原生晴天 rear 图中，上方中央白板之间存在显著矩形黑区，边缘还可见细窄亮色间隙。图像足以证明其可见，但不足以判定是源模型开放边界、遮挡缺失还是未照亮的凹腔。必须核查具体几何、alpha 和射线命中，不能直接将其当作正常阴影通过。
3. **近景轮廓和表面仍显模型感。** 原生 window-rim 显示圆角由可辨认直线段组成，部分层叠密封条折角明显。原生 rear 可见真实建模的门锁、舱门和框架，但大面积舱壁仍呈均匀白平面；多个孔、标识及面板细节主要停留在贴图层面。NASA 数据本身和贴图修复带来了更丰富的机械信息，但当前取景尺度、光照和材质响应尚未达到照片级。
4. **三相整体画面尚不充分。** 晴天与黄昏的天空、窗沿有可见区别，后舱却基本维持同样的亮度和观感。当前离线结果不足以确认三相具有连续、可信的室内外照明关系；运行时独立天空的最终视觉与交互仍需另行实际检查。

下一轮应先核实后舱黑区的成因，调整 Cupola 与 Node3 的局部光比，并在同一相机、同一材质基线下比较三相六向及上述三个近景。保留源几何与 UV 的声明必须与实际改动一致；如修补边界或增添遮挡件，应记录为新增内容。取得新图并实际审查后再决定验收结果，不能用本轮的技术接入成功抵扣图像质量问题。
