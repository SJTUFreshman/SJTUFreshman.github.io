# 连续银河探索（本地预览）

`life.html` 现在使用一套固定世界坐标，在附近星群和整个银河之间连续移动。
滚轮不再触发 `showGalaxy()` 的定时飞行动画，也不改变恒星坐标、镜头倾角或视场角。
原有桌面初始视角（yaw 0、pitch 0.48、distance 430）和手机初始构图保留。

## 操作

- 滚轮、触控捏合、右下角的 `− / +`：连续拉远、拉近。
- 原有右键拖动或触控板双指滑动：环绕当前观察点；左键拖动：平移。
- `W / S`：沿当前视线前进、后退；`A / D`：横向移动。
- `Q / E`：沿画面竖直方向下降、上升；`Shift`：三倍速度。
- 移动键自动进入自由飞行。此时右键拖动在相机当前位置环顾。
- “环绕观察”恢复围绕前方观察点旋转。“初始视角”或 `R` 返回起始构图。
- 手机点击“自由飞行”可展开六个方向按钮，按住即可移动。
- 切换窗口、打开卡片/菜单/对话框和按 `Esc` 都会清除持续移动输入。

移动速度随所在尺度平滑增加。斜向移动经过归一化；滚轮尚未停稳时按移动键，
会保留剩余缩放行程并平滑叠加移动，不会跳到缩放终点。没有自动环绕或自动跳回局部星图。
从银河尺度通过生活目录打开卡片，关闭后会回到打开前的位置与控制模式。

## 空间与数据

全局模型以秒差距为距离单位，太阳保持原来 `[-47, 10, 6]` 的位置。
银心位于 `[-47, -10.8, 8184]`，对应太阳距银心 8.178 kpc、位于参考银面上方 20.8 pc。
这些是采用的模型参数，并非对太阳位置的最新测量声明。
原有银河重建纹理的一个单位对应 40 pc，盘面直径约 32 kpc（约 10.4 万光年）。

局部高细节星群、云层与整体银盘使用同一相机和固定坐标。
ESO 全天照片只在太阳附近作为角度背景使用，离开其适用范围后连续减弱。
整体密度绘制接替局部细节时只改变贡献权重，恒星不移动、银河不缩成另一套坐标。
近处恒星随距离减弱，远处不能分辨的恒星由连续光度密度表示。

整体盘面沿用 [ESA/Gaia 2025 银河重建](https://www.esa.int/ESA_Multimedia/Images/2025/01/The_best_Milky_Way_map_by_Gaia)
及已有的尘埃纹理，保留原授权和页面署名。它具有薄盘、厚盘、中央核球、尘埃层和外盘翘曲。
新增 64,000 个确定性采样的恒星点，其平面密度来自重建图，垂向分布来自薄盘/厚盘/核球模型。
这些点是恒星群的可视化采样，不是新增的逐星观测。

**真实性边界：** 为保留用户认可的初始星图，八个生活星座仍使用原先的导航编排，
附近 Hipparcos 恒星也保留原先经过压缩的展示距离。这部分不能当作精确三维星表。
银河系没有从外部拍摄的全貌照片，也没有覆盖全银河每一颗恒星的三维观测；
整体银河和未测部分属于有观测参考的模型。右下角距离为近似模型尺度。
`observatory.html` 仍保留其独立的太阳系观景模式。

## 渲染与验证

主体延续现有 WebGL 渲染器与星点风格，没有引入新的框架或外部运行时服务。
盘面仍在原画布中绘制；星位缓冲区不因缩放改变。两张银河纹理提前异步准备，
不阻塞相机；加载失败会生成程序盘面。WebGL 上下文丢失时使用具有同一坐标的
Canvas 透视网格，恢复后重新上传纹理与恒星缓冲区。

全景采用原生 5000 像素星光纹理和 4096 像素无损尘埃纹理，减少原素材处理时的柔化。
桌面全景恢复高清画布与更细的体积采样；触控设备限制上传尺寸和像素比例。
纹理格式、显卡适配及来源说明见 `assets/life/galaxy/README.md`。

在本地 HTTP 服务上运行：

```text
node scripts/validate-continuous-galaxy.cjs http://127.0.0.1:8797/
node scripts/validate-life-card-updates.cjs http://127.0.0.1:8797/
node scripts/validate-solar-destination.cjs http://127.0.0.1:8797/
node scripts/validate-life-http.cjs http://127.0.0.1:8797/life.html
```

脚本通过 `PLAYWRIGHT_MODULE_PATH` 指定已有的 Playwright 安装，使用本机 Chrome。
连续探索检查覆盖旧缩放边界、固定坐标、往返、卡片返回、键盘/触控、混合输入、输入焦点、
减少动态效果、侧面/正面视角、高清纹理上传、低纹理上限、上下文丢失恢复与纹理请求失败。
截图和检查报告输出到忽略目录 `.render-work/continuous-galaxy/`。

本次改动只用于本地预览；不提交、不推送、不运行 Cloudflare 发布。
不要用旧版 `site_content.json` 全量重新生成页面。
