# NASA 视觉材质对照（2026-09-21）

本轮是离线 NASA 源资产诊断，不是 Life 四场景连续验收，也没有安装全景或修改 manifest。

- A800 作业：`167850`，分区 `hp_a800`，源 FBX SHA-256 与官方记录一致。
- 对照顺序：原始导入材质；同时启用 `repair_pbr` 与 `authored_surface_response`；保留两项改动并隐藏七个窗盖和内层玻璃，启用透明背景。
- 结果文件：`.render-work/nasa-inspect-20260921-r4/`。

三张 1600×1100、64 samples 的实际图片均已独立打开检查，并对照 `inspection.json` 核查。第一张右侧三个显示器呈白色，源 `Generic_Misc_Details` 的 Base Color/Metallic 没有贴图连接；第二张显示器恢复画面、边框颜色及标识。这项变化对应 `repair_pbr` 连接 NASA 原有的 Diffuse/Metallic 贴图，不能称为粗糙度优化消除了白塑料感。

`repair_pbr` 还同时改变玻璃的 Metallic、Transmission、Alpha 和 Roughness；`authored_surface_response` 为 35 个材质增加 Diffuse 明度到 Roughness 的重映射。第二张因此包含多项材质变化，没有同机位、同光照、同可见性且只启用 `repair_pbr` 的中间对照。当前图片只能证明组合变体成功渲染，不能证明粗糙度重映射单独改善真实感。该重映射是人为诊断解释，不是 NASA 原始粗糙度数据。

进一步核查发现，r4 第三张的视图条目漏填 `world_color` 与 `world_strength`，实际使用脚本默认色 `[0.32, 0.38, 0.46, 1]`、强度 `0.22`；前两张为 `[0.45, 0.56, 0.7, 1]`、强度 `1.2`。第三张因此不能作为同光照的开窗亮度对照，图中欠曝也不能单独归因于源资产或粗糙度。透明 alpha 的结论不受这项光照差异影响。

第三张中七个窗口的 RGBA 开口成立。独立读取 PNG alpha 后，530,102 像素为 0（30.1194318%），14,917 像素在 1–254 之间，1,214,981 像素为 255。以左上角为原点，七窗内采样 `(800,550)`、`(220,320)`、`(810,80)`、`(220,800)`、`(810,1030)`、`(1450,340)`、`(1450,800)` 的 alpha 均为 0；窗框 `(1000,490)` 和显示器 `(1220,500)` 的 alpha 均为 255。前两张全图 alpha 为 255。该检查证明当前 Cupola 透视机位保留真实透明开口，没有验证完整 Life 全景或浏览器天空/点击集成。

本轮仍不通过照片级验收：舱内严重偏暗，窗框近景轮廓仍能看到分段，多处小细节依赖平面贴图；未检查 US Lab 大面积舱壁，也未完成六向、晴天/黄昏及运行时交互。物理尺度仍未标定。连续干净审查轮数保持 **0**，不安装全景，不更新 manifest。

## r5 同条件材质对照

A800 作业 `167947` 的三张图位于 `.render-work/nasa-controls-20260921-r5/`，均已独立打开审查。每张为 1600×1100、96 samples，使用同一机位、85°垂直视角、`[0.45, 0.56, 0.7, 1]` 环境色、`1.2` 环境强度、透明背景，并隐藏相同七个窗盖和 `Cupola_Int_Glass`。`inspection.json` 的逐视图 `material_state` 分别为原始导入、只修复贴图与玻璃参数、再增加粗糙度重映射；第二至第三张这次具有相同的渲染条件。

第一至第二张明确恢复了三个显示器的画面、深色外框和标识，确认这些是连接原有 Diffuse/Metallic 的效果。第二至第三张的显示内容及几何不变，窗框、金属和暗面局部高光发生轻微变化，证明可选粗糙度响应实际生效。但实际图中没有足够证据判定它提高了照片级真实感；其变化没有解决低照度下舱内结构不清、窗框轮廓分段和细节平面化。保留 repair-only 为后续可比较基线，粗糙度变体继续隔离，不能按“改善已通过”进入成品。

三张图片 SHA-256 均与报告一致；逐图 alpha 复核如下：

三张图在 r4 记录的相同七个窗内坐标处 alpha 均为 0，窗框和显示器采样均为 255。repair-only 与 authored-response 的 alpha 并非逐像素完全一致：683 个像素不同，差值最高 9/255，全部位于至少一图的部分透明边缘；没有全透明与全不透明互换的像素。该结果支持七窗开口未被材质响应堵塞，不能称整张 alpha 完全相同。
