# 银河外观素材

ESA/Gaia/DPAC, Stefan Payne-Wardenaar.

纹理改编自 ESA 于 2025 年发布的 [The best Milky Way map, by Gaia](https://www.esa.int/ESA_Multimedia/Images/2025/01/The_best_Milky_Way_map_by_Gaia)。[原始 JPEG（5000 × 5000）](https://www.esa.int/var/esa/storage/images/esa_multimedia/images/2025/01/the_best_milky_way_map_by_gaia/26530986-1-eng-GB/The_best_Milky_Way_map_by_Gaia.jpg) 是基于 Gaia 观测的艺术重建：旋臂较不规则、不突出，中央棒的朝向也不同于旧的 Spitzer 示意图。银河系目前没有从外部拍摄的全貌照片；远侧结构仍有推定成分。

侧面结构参考同一作者的 [Gaia edge-on reconstruction](https://www.esa.int/ESA_Multimedia/Images/2025/01/The_best_Milky_Way_map_by_Gaia_edge-on)：薄盘、暗尘埃带、突出的核球和轻微翘曲。运行时厚度与遮挡属于可视化估计，不是反演出的三维密度数据。

质感对照 [ESO 对银河类似星系 NGC 6744 的可见光观测](https://www.eso.org/public/images/eso1118a/)，检查暖色中央恒星、较蓝的年轻恒星区和不连续的尘埃暗带。该观测仅作视觉参考；页面纹理仍来自银河自身的 Gaia 重建。

这两个派生纹理按原图的 [CC BY-SA 3.0 IGO](https://creativecommons.org/licenses/by-sa/3.0/igo/) 授权分发。页面星图说明保留完整署名、来源链接、许可和改编说明。

## 文件

- `milky-way-starlight.webp`：5000 × 5000，保留原图原生尺寸，采用无损 WebP。取消前置柔化，保留原图中的细恒星和尘埃纹理；对 1.1 与 4 像素尺度的亮度残差分别施加 0.65、0.25 的细节增强，忽略不足一个灰阶的变化，将单像素调整限制在 ±0.035，避免明显光晕。淡出边缘并移除原图顶部的人马座矮星系，避免把盘外天体投影到银河盘上。显示调色压低弥散星光的紫红偏色，保留暖白中央棒、偏蓝的年轻恒星区和少量红色发射区；在尘埃丝状结构的尺度上增强局部明暗，压低均匀雾光。这是重建图的显示处理，不是新的测光标定或真实颜色测量。
- `milky-way-dust.webp`：4096 × 4096 的不透明 RGB 数据纹理，采用无损 WebP，避免细尘埃和独立数据通道被有损压缩混合。R 为根据局部暗部和暖色估计的尘埃遮挡，G 为分离的核球亮度，B 为核球蓝红比。使用不透明通道避免浏览器预乘 alpha 损失数据。
- 原始 JPEG 的 SHA-256：`210366dd8e7b9167bdae2a648eacd1b482b6493e1212696ae8207d8b1a880741`。

星光薄盘在最终画布分辨率下投影，并使用最高 16 倍各向异性过滤保留斜视细节。核球单独进行 32 步体积积分，侧视恒星盘和尘埃采用 128 步积分。年轻恒星分配到较薄的层，老年恒星分配到较厚、偏暖的层；两层按 RGB 通道归一，保留正面总光度。弥散尘埃随半径衰减，窄尘埃层遮住侧视核球的中央部分。各厚度仍是示意参数。全景的平滑体积层在桌面使用 0.75 倍视口尺寸绘制（上限 1200 × 900），再与清晰的盘面合成。银河画布在桌面支持最高 DPR 3、触控设备最高 DPR 2，总像素上限约 830 万。Canvas 降级也直接使用高清纹理；星图不叠加装饰性颗粒。

两套星图渲染器上传纹理时都适配 WebGL 1 的 mipmap 限制：桌面将 5000 像素星光图重采样到 8192，以保留原图细节并支持远景过滤，这并不增加原图之外的真实信息。触控设备、报告内存不超过 4 GB 的设备将上传限制在 4096；更低的显卡纹理上限仍会被遵守。缺少 `createImageBitmap` 时用 Canvas 完成同样的尺寸适配。

清晰盘面使用 −0.35 的 mipmap 采样偏移，在保留三线性与各向异性过滤的同时减少远景的过度柔化；体积积分层继续采用原采样方式。官方当前提供的最高分辨率为 5000 × 5000，本次改善来自保留源图细节、无损编码与采样调整，没有声称新增原图不存在的信息。纹理上传尺寸和显存预算保持原值。

正面及斜视的核球也按前后关系接受尘埃遮挡：在视线与翘曲薄盘的交点计算尘埃柱，只衰减尘埃后方的核球光。这样可以在较低的核球采样数下保留窄暗带，并避免中心光无条件透过前景尘埃。

## 重建

需要 Python、Pillow 和 NumPy。在仓库根目录运行：

```powershell
python scripts/build-galaxy-assets.py
```

脚本优先使用 `.render-work/gaia-milky-way-original.jpg`，缺失时从 ESA 下载。可用 `--source` 指定已下载的原图。运行时只加载本地生成文件，无需向 ESA 发起请求。两张纹理共约 34.3 MB（星光 24.2 MB、尘埃 10.1 MB），均低于 Cloudflare Pages 单文件 25 MiB 的上限。首次加载比有损版本更大，仍异步加载并在完成后刷新静止视图；网络失败时保留程序生成的兜底盘面。银河的厚度、翘曲和标签位置仍属于导航示意。
