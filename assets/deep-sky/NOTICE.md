# Deep-sky telescope observations

These local images are photographic observations published by NASA, not
generated images or volumetric reconstructions. Colors encode the specified
observing bands and should not be interpreted as the naked-eye appearance.
The site permits panning and magnifying the flat observations; it does not
invent unobserved viewpoints through these objects.

## Orion Nebula: `m42-hubble-spitzer.webp`

- NASA image ID: **PIA01322**, *Chaos at the Heart of Orion*.
- Telescopes: Hubble and Spitzer; visible-light and infrared composite.
- Credit: **NASA/JPL-Caltech/STScI**.
- Image record: https://images.nasa.gov/details/PIA01322
- Downloaded image: https://images-assets.nasa.gov/image/PIA01322/PIA01322~medium.jpg
- Object reference: https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-42/
- M42 is a star-forming emission nebula (an H II region) **inside the Milky
  Way**, approximately 1,500 light-years away. It is not an external galaxy.
  The rounded distance follows NASA's public object and image descriptions;
  it is not an exact measured distance to every part of the cloud.

## Processing and use

Retrieved from NASA's Image and Video Library on 2026-09-29. The input JPEG
is 1280 × 1280 pixels. It was converted to RGB WebP using Pillow with
`quality=89, method=6`, preserving original dimensions and composition.
There is no recoloring, image synthesis, retouching, or additional imagery.
Source mosaic footprints and blank areas remain as published.

The public NASA imagery is reproduced with the source credits above.
